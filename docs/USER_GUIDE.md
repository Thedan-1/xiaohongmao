# 使用指南

## 安装与预览

- 日常使用：下载 Releases 中的安装 EXE，选择位置、阅读协议并安装。
- 本机体验：完整解压预览 ZIP，运行“小红帽预览.exe”；不要只移动 EXE。
- 两种版本功能相同，使用不同的数据目录，互不覆盖账号和项目。

Windows 10/11 x64。客户端包含 Python 运行环境；缺少 WebView2 时按微软组件安装提示处理。

## 连接与配置

在官方页面完成小红书登录，核验通过后进入工作台。密钥、接口、模型与估算单价在“设置 → 模型与 API”配置；“用量与预算”可调整本机上限，保留以前的用量记录。

## 日常流程

描述需求 → 确认搜索方向与数量 → 查看候选 → 准备逐条预览 → 确认当前批次发送。自然语言的明确确认与按钮确认共用记录。修改对象、内容或账号后应重新核对。

发送结果不明的条目不会自动重发。平台限制或验证需要在官方页面处理；软件不能保证每次平台操作都能成功。

## 更新

启动时检查 GitHub 正式版本，也可在“设置 → 关于”手动检查。选择下载后会校验大小和 SHA-256；在空闲时选择重启更新。关闭更新提示可继续使用当前版本。

0.7.0 以前的客户端没有内置更新器，需要手动安装或替换预览包一次。

## 数据

安装版 `%LOCALAPPDATA%\Xiaohongmao`；预览版 `%LOCALAPPDATA%\XiaohongmaoPreview`。升级不重置密钥、登录、预算记录或项目。请自行备份重要资料；卸载默认保留用户数据。
