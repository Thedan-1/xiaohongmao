## 小红帽 0.7.0

增加 GitHub Releases 更新：发现新版本后提示，用户选择下载，校验通过后在任务空闲时选择重启更新。

- 安装版：下载 `xiaohongmao-0.7.0-windows-x64-setup.exe`。
- 免安装体验：下载 `xiaohongmao-0.7.0-windows-x64-preview.zip`，完整解压后运行“小红帽预览.exe”。
- 公开包不含预填密钥、账号或聊天记录；密钥与费用上限由每位使用者设置。
- 升级保留本机项目、登录和配置；预览版保留上一程序目录。
- 0.7.0 之前的版本需要手动升级一次，此后可从客户端检查并选择更新。

当前淘宝模块仍处于实验验证阶段，未打通真实收发，不作为本发行版能力。

Windows 10/11 x64；需要 Edge 和 WebView2（缺少时按微软组件提示安装）。当前程序未提供代码签名。
