## 小红帽 0.7.1

修复 0.7.0 线上检查发现的问题：匿名 GitHub API 可能达到共享请求额度，导致客户端无法检查新版本。现在优先读取 Release 中的公开静态 `update.json`，无需 GitHub Token。

- 安装版：`xiaohongmao-0.7.1-windows-x64-setup.exe`。
- 免安装体验：`xiaohongmao-0.7.1-windows-x64-preview.zip`，完整解压后运行“小红帽预览.exe”。
- 启动时及约每六小时检查；用户选择下载，校验通过后在空闲时选择重启更新。
- 公开包不含预填密钥、登录或聊天记录；升级保留本机数据。
- 安装版升级原目录；预览版切换到新目录并保留旧版程序。

0.7.0 及更早的版本建议先手动升级到此版本，随后使用内置更新功能。

淘宝模块仍处于实验验证阶段，未打通真实收发，不作为本发行版能力。Windows 10/11 x64；当前程序未提供代码签名。
