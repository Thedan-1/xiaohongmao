小红帽 0.7.0 · Windows 客户端

安装
双击安装程序，阅读并同意使用协议，选择安装位置。可选择创建桌面快捷方式。安装完成后，从开始菜单或桌面打开“小红帽”。不需要安装 Python，不需要与其他使用者处于同一网络。

第一次打开
客户端会初始化本机工作台。Windows 若缺少 WebView2 Runtime，按提示安装 Microsoft 官方组件；此步骤需要网络。请不要只移动或复制安装目录里的 EXE，应使用安装程序在另一台电脑安装。

AI 设置
从左下角个人菜单打开“设置 → 模型与 API”，填写自己的 HTTPS 接口根地址、API Key、模型 ID 和估算单价。可读取服务的模型列表，也可手动填写。输入框下方的模型菜单也能进入此设置。公开版不内置密钥；已有个人配置不会被升级覆盖。
在“用量与预算”中设置本机费用上限；修改上限会保留以往用量。费用按所填单价估算，实际账单以服务商为准。AI 请求可能产生服务商费用。

小红书登录
首次启动会打开客户端内的小红书官方登录页。扫码或使用官方手机号验证后，客户端会检测并核对账号，成功后自动进入工作台；未自动切换时可返回工作台，从个人设置重新打开登录。以后也可通过左下角“设置 → 账号与登录”或顶部菜单登录、切换账号。工作台不代收您的密码；官方页面和本机专用执行浏览器之间只在本机连接登录状态。平台如要求额外验证，请按官方提示处理。

使用与退出
在对话中描述要查找的内容，根据界面提示确认方向、数量和后续动作。检查预览中的对象与文字后再决定是否执行。关闭窗口或“小红帽 → 退出”会退出客户端；任务正在执行时会提示处理方式，请先确认任务状态。

记录在哪里
点击“小红帽 → 打开数据文件夹”。默认目录是 %LOCALAPPDATA%\Xiaohongmao。程序安装目录与用户数据分开，重新安装或升级会保留已有数据。请自行备份重要记录。

卸载
可从 Windows“设置 → 应用”或开始菜单“卸载小红帽”卸载。请先正常退出客户端。卸载默认保留项目、登录记录和配置；如需完全清除，先备份必要资料，再由您自行删除数据目录。

遇到问题
如果初始化失败，查看客户端显示的原因，必要时使用“重新连接”。向软件提供人反馈版本和错误信息时，请隐藏 API Key、Cookie 和个人信息。

版本更新
客户端启动后会检查 GitHub 正式发布。发现新版时可选择下载；下载后校验 同一 Release 清单中的 SHA-256，在任务空闲时选择重启更新。安装版覆盖原程序目录，预览版切换到新程序目录并保留上一版。项目、登录和密钥保存在程序目录之外。连接 GitHub 失败时可继续使用当前版本，也可从 Releases 页面手动下载。
