小红帽隐私与数据说明
版本：0.6　更新日期：2026年10月23日

1. 本机保存什么
软件在 %LOCALAPPDATA%\Xiaohongmao 中保存项目对话、采集结果、发送记录、截图、错误日志、AI 使用记录及 API 配置；专用浏览器的登录状态也保存在该用户的数据目录中。客户端界面、内置小红书官方登录页和专用执行浏览器使用不同的子目录。点击“完成登录”后，官方登录会话在本机交给执行浏览器并验证；会话不会写入聊天、发送给 AI 或打包进安装程序。

2. 什么会发送到外部
您使用搜索、登录及平台操作时，相应平台会按其规则接收网络请求。启用 AI 分析或生成时，任务指令及相关的正文、评论或其他必要上下文会发送至您配置的 AI 服务。API 密钥会用于该服务的身份验证。具体保存期限和处理方式以第三方服务的隐私政策为准。

3. 安装和首次运行
软件在本机启动辅助服务供客户端访问。若电脑缺少 Microsoft Edge WebView2 Runtime，首次启动可能提示安装 Microsoft 官方运行环境；这一步需要联网。软件的普通版不附带他人的账号登录状态、项目记录或 API 密钥。内部专用版包含经授权预置的默认 API 配置，但不包含原作者的小红书登录状态或项目记录。

4. 升级、卸载与备份
升级程序不会主动删除用户数据；卸载仅删除安装的程序和快捷方式，默认保留本地用户数据。卸载后如需删除用户数据，请先确认备份及密钥安排，再自行处理该目录。删除项目或记录可能影响重复发送核对，请谨慎操作。

5. 共享设备
能访问您的 Windows 用户目录的人可能访问本地记录和配置。请妥善管理设备和软件包；不要公开分享含密钥的内部安装包。

6. 问题反馈
分享日志或截图前，请检查并移除不必要的个人信息、API 密钥、Cookie 和访问令牌。
