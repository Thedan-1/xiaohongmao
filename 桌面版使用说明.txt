小红帽 Windows 桌面版 v0.4（免安装）

1. 将整个 ZIP 发给对方。对方先完整解压到自己的文档目录。
2. 双击 小红帽.exe；无需安装 Python，需 Windows 10/11 x64 和 Microsoft Edge。
3. 首次弹出初始化界面，填写自己的或管理员提供的 DeepSeek API Key。
   暂不配置也可以进入；AI 对话需要有效密钥以及联网。
4. 工作台以独立窗口打开。点击右上角账号 → 小红书窗口，在官方页面登录。
5. 回到工作台刷新账号，输入搜索需求；预览后自行选择是否发送。
6. 退出后台可双击 EXIT.cmd。只关闭工作台窗口时后台任务可能仍在运行。

数据在本机此文件夹的 data 中；登录状态、项目与其他电脑完全独立。
不同网络也能使用，不需要连接发布者的电脑；127.0.0.1 指使用者自己的电脑。
不要只发 EXE，必须发整个 ZIP。不要发送使用过的 data 或 deepseek.local.txt。
修改密钥：用记事本打开 deepseek.local.txt，修改等号右侧，或运行 小红帽.exe --settings。
本版是独立窗口桌面入口，尚无安装向导、自动更新和代码签名。
未签名程序可能出现 Windows 提示，请核对来源与 SHA256；不要关闭系统安全功能。
默认 AI 预算上限为人民币5元，在本机持续累计，达到后停止，不自动充值。
